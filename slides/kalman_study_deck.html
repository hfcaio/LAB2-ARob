Kalman filter for roll and pitch

What we model, why the gyro is an input, and how Q4.1 becomes Q4.2 – Q4.7

Sources: Ch5-6 lecture slides 12–28 and Lab 2 guide §4 (full text read; slide equations read from rendered pages)
Problem

Each sensor alone gets the angle wrong

Rate gyro p, q

Measures the rate of the angle. Very clean at high frequency.

Integrating it drifts: any constant bias becomes a ramp in the angle.

Inclinometer φm, θm

Computed from the accelerometer (Q3.4). Measures the angle itself, no drift.

Noisy, and corrupted by vibration and acceleration of the vehicle.

Kalman filter

Fuses both: trust the gyro in the short term, the inclinometer in the long term. The balance is set by Q and R.

Key idea

The gyro is an input, not a measurement

Gyro → input u

Measures the derivative of the state: qm = θ̇ + noise. Its noise is the process noise w → Q.

Inclinometer → output y

Measures the state: θm = θ + noise. Its noise is the measurement noise v → R.
Source: Ch5-6 slides 17–19, 28; Lab 2 guide Q4.1 · full text
Q4.1 model · one angle

Pitch (and roll) as a state-space model

θ̇ = qm + w
y = θ + v

y is the inclinometer reading θm (noise included in v). E[w²] = Q (gyro noise), E[v²] = R (inclinometer noise)

Matches ẋ = Ax + Bu + Gw

A = 0
B = 1 (u = qm)
G = 1
C = 1

Observable: (A, C) = (0, 1) has rank 1.

Roll is identical with φ, pm, φm. Q from the gyro variance in Exp A (Q3.1); R from the inclinometer variance (Q3.4).

Question: why a Riccati equation?

Kalman is the dual of LQR, same equation

LQR

Choose K to minimise ∫ xᵀQx + uᵀRu.

Needs the Riccati equation for (A, B).
⇄

Kalman filter

Choose L to minimise the error covariance Σ = E[x̃x̃ᵀ].

Needs the same Riccati equation with A→Aᵀ, B→Cᵀ, Q→W, R→N.
L = Σ∞ Cᵀ N⁻¹ where Σ∞ solves (A−LC)Σ + Σ(A−LC)ᵀ + W + LNLᵀ = 0

You never write it: kalman() solves it. It appears only because L is defined as the gain that minimises the estimation error.

Source: Ch5-6 slides 12–14 (duality slide 14) · full text
Closed form for our case

L = √(Q/R): one number sets the filter

A = 0, C = 1
Σ = √(QR)
L = Σ/R = √(Q/R)

Pitch

Q = 7.6e-4, R = 8.1e-4
L ≈ 0.97 rad/s

Roll

Q = 5.3e-5, R = 4.3e-5
L ≈ 1.11 rad/s

Only the ratio Q/R matters. Bigger Q or smaller R → larger L → trust the inclinometer more (this is Q4.3). Values from your setup_4_1.m, still marked TODO; computed here from the formula, not run.

This is Q4.2 (and 4.5)

Freeze L, get two transfer functions

(s + L) θ̂ = qm + L θm

θ̂ = L/(s+L) θm + s/(s+L) · qm/s

GL (low-pass on the inclinometer) + GH (high-pass on the integrated gyro) = 1 → complementary, which is Q4.5.

Magnitude, L = 0.97 rad/s

Takeaway

What to carry into the report

Decision

Model each angle as θ̇ = qm + w, y = θ + v. Gyro = input, inclinometer = output.

Reason

Gyro has the drift, inclinometer has the noise. L = √(Q/R) sets the crossover; Riccati is just how L is defined as optimal.

Orin Nano

Not part of this lab. A steady-state filter is a few multiply-adds per step, so cost is negligible (not measured).
